# Effort logs and incident records

One file per large effort (a migration, a build-out, a cleanup, an incident), named `<effort>-log.md` or `incident-<date>-<topic>.md`. Chronological, append-only, with the rule "when two entries disagree, the later one wins". Use the incident and changelog formats from the methodology. A "before" snapshot (`<effort>-before.md`) lets a later change be compared with its starting point.
