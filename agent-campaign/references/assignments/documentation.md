# Documentation

A documentation assignment writes or corrects docs: guides, references, READMEs, design notes.

- Plain technical prose by default: what it is, how to use it, what it guarantees, with commands
  and paths a reader can run. Follow the project's documentation conventions. A personal
  writing-style skill only when the prompt names it for public-facing writing the owner asked for.
- Every command, path and number comes from running it or from a cited file; mark anything you
  could not check.
- Change no code. Where the docs and the code disagree, report both `file:line` under "Blocked on".
